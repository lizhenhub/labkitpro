The three-step method (ISO official: Prepare → Connect → Integrate)Following ISO’s official Integrated management systems practical guide, break the integrated transition into three steps and nine actions — this is your project execution framework.▾

The three steps

  • Step 1 · Prepare — Leadership alignment and scope: top management commits to one transition for all three; define the integrated scope (sites / products / activities); appoint a single management representative for the integrated system; estimate the share of common documents. Key move: get the three transition timelines (14001 earliest, 2029-04-30) and let the earliest cutoff set the project cadence.
  • Step 2 · Connect — Map each standard’s requirements onto existing processes: use the shared-chapter map to mark shared / shareable / standalone; map the two new editions’ changes (9001 culture & split, 14001 expansion & change management) into shared processes; build a shared risk-opportunity register (quality / environment / safety in columns). Key move: by the end of this step you hold a three-way requirements→process→document matrix.
  • Step 3 · Integrate — Close gaps and embed into daily operations: revise shared documents per the matrix; combine the audit programme and run one management review; embed culture, change and emergency routines into existing meetings and dashboards rather than parallel mechanisms. Key move: the acceptance test is “an auditor can’t tell this was three systems stitched together” — one numbering scheme, one record format, one dashboard.

Three-step self-check (9 actions)

  • Prepare: top management signs one integrated-transition decision (one document, not three).
  • Prepare: integrated scope and site list finalized; a single management representative appointed.
  • Prepare: three cutoffs on the wall, with 14001 (2029-04-30) setting the pace.
  • Connect: mark the shared-chapter map item by item (shared / shareable / standalone).
  • Connect: map the new-edition changes into shared processes (9001 culture & split; 14001 expansion, change management, emergency scope).
  • Connect: shared risk-opportunity register built (quality / environment / safety columns, one mechanism).
  • Integrate: shared documents revised; one numbering scheme and format.
  • Integrate: run one combined audit programme cycle; one management review covering all three.
  • Integrate: culture, change and emergency routines embedded in existing meetings and dashboards.

Gap checklist (tick off as you close)Six integration actions: shared documents, merged culture, one framework, one audit, 45001 pre-study, staggered calendar — tick off as you close.▾

Gap checklist (tick off as you close)

  • List the shared controlled documents (use the map): one numbering scheme, one revision, effective for all three. Done when: the shared share is quantified (aim ≥60%) and the directory is merged.
  • Merge 9001 quality culture, 14001 environmental culture and 45001 safety culture into one “organizational culture” leadership process. Done when: one procedure, one indicator dashboard, one standing review item.
  • Use 14001’s 6.1.4/6.3 as the shared risk and change framework, with the shared register running in columns. Done when: risks, opportunities and changes from all three systems live in one register and one process.
  • Combine the audit programme and run one integrated audit + one management review for all three. Done when: one programme, one integrated audit report, one review minute (with decisions for all three).
  • Do the 45001 “expected” pre-study: prepare shared interfaces for hazards / participation / emergency along the DIS direction; align via the free update once published. Done when: the pre-study list exists and alignment completes within 90 days of publication.
  • Stagger the certification calendar: 14001 (2029-04-30) first, 9001 (2029-09-30) next, 45001 (expected ≈2030) later — schedule each transition audit into the nearest surveillance/recertification window. Done when: all three transition-audit dates are confirmed with the certification body.
