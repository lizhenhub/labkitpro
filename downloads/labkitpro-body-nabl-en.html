NABL · Specific Requirements Beyond ISO/IEC 17025:2017

NABL · Specific Requirements Relative to ISO/IEC 17025:2017 — Explained

NABL (National Accreditation Board for Testing and Calibration Laboratories), under the Quality Council of India (QCI), is India's national accreditation body. Its defining feature is the "three-piece set" that always goes together: for each laboratory type, one Specific Criteria (NABL 1xx) + one Application Form (NABL 15x) + one Assessment/Document Review Checklist (NABL 21x/22x), together with metrology technical policies (141–144/163/164) and QMS guidance (160/161).

1

Relationship to ISO/IEC 17025:2017

Three-piece set · criteria by body type

On top of ISO/IEC 17025:2017, NABL issues a "Specific Criteria + Application Form + Checklist" trio for each laboratory type: the criteria define the sector-specific additional requirements, the application form sets the reporting basis, and the checklist is the assessment baseline — the three must be used together; none can stand alone.

Layered document system

Layer 1 · International baselineISO/IEC 17025:2017 (testing/calibration), ISO 15189:2022 (medical), ISO/IEC 17043:2023 (PTP), ISO 17034:2016 (RMP), ISO 20387:2018 (biobanking)
Layer 2 · Overarching policiesNABL 100B Process & Procedure + 131 Terms & Conditions + 133 Symbol & claims + 132/134 complaints & appeals
Layer 3 · Sector-specific criteriaNABL 12x/11x/22x (calibration/site/medical/imaging/software IT/air quality/drinking water/soil/biobank, etc.)
Layer 4 · Metrology technical policiesNABL 141 uncertainty, 142 traceability, 143 CMC, 163 proficiency testing, 164 alternative interlaboratory comparison, 144 remote assessment
Layer 5 · Application forms & checklistsNABL 15x application forms + 208–220 pre-assessment/assessment/document-review checklists (the application-assessment interface of the trio)

Practical Points & Common Pitfalls

5 tips

The NABL system runs on a matched "three-piece set"; the most common miss is that the application form/checklist are not updated in step with the criteria.

1The trio travels together: criteria + application form + checklist

Each laboratory type = Specific Criteria (1xx) + Application Form (15x) + Assessment/Document Review Checklist (21x/22x) — used as a set.Taking only the criteria without the forms means missing the reporting basis

2Pick the criteria by body type

Calibration 129, site 130, medical 112A, software/IT 137, imaging 135, biobank 229, PTP 181A, RMP 191 — lock the type first.Pick the wrong type and the whole file set is wrong

3Regulated industries go through integrated assessment

Regulated industries follow the 127 integrated-assessment procedure + regulatory extras, with the dedicated 154/233/237 application forms — defence aviation via DGAQA, HIV network via NACO.Ordinary application forms do not apply to integrated assessment

4The five-piece metrology set

142 traceability / 143 CMC / 141 uncertainty / 163 proficiency testing / 164 alternative comparison — calibration labs need all five; electrical testing refers to the 174 worked examples.Missing any one policy can draw a nonconformity

52026 wave: download the latest forms before filing

Application forms (151–153/180/190/227) revised 2026-08-18, the 220-series document-review checklists revised 2026-09-22, and the 131 terms revised 2026-01 — check the revision dates before filing.Filing on an old form version gets rejected
