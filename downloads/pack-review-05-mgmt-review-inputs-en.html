Management Review Inputs (Structured Collection Cards)

Collects all 15 inputs of §8.9.2 a)–o) item by item. Each item is broken down into purpose / data dimensions / data sources / how to write the conclusion / red lines, ensuring the information is complete — the sole evidence base for the management review report.
Doc No. MR-03 Version V2.0 (collection-card upgrade) Covers §8.9.2 a)–o) (15 items) Led by: Quality Manager
Filling rules: ① each item must contain “data + evidence reference + conclusion” — never write only “normal / fine / no change”; ② conclusion models are given in each card as “good example vs. perfunctory example”; the Quality Manager returns non-compliant submissions 5 working days before the meeting; ③ evidence references point to original records (e.g. FR-25, complaint ledger, QC summary) for traceability; ④ insufficient information = management review conclusions without basis = the review is ineffective.
a　Changes in internal and external factors relevant to the laboratory §8.9.2 a
PurposeIdentify the impact of external changes (regulations / market / customer industries / accreditation requirements) and internal changes (strategy / organisation / resources) on the appropriateness of the system, and decide whether the system needs revision.
Data dimensions
Regulatory / standard changes[ total __, addressed __, not addressed __ ]
Market / customer industry changes[ describe: ]
Parent-body / shareholder strategy changes[ describe: ]
Triggered system revisions[ __ documents need revision ]
Data sources / ownerRegulatory tracking records, market analysis, management input ／ Quality Manager

Perfunctory: “No change.” (Red line: classifying actual regulatory updates as no change)
