A2LA Accreditation Documents · By-Sector Classification

The official A2LA public document portal (portal.a2la.org/documents) is organised by document type (Organization / Information / Policies / Requirements / Guidance / Forms) rather than by testing field. This classification therefore re-groups the 99 current documents in the full-list volume as “general management + calibration-specific + field-specific testing + specific regulatory programmes”. Group names come from A2LA accreditation programmes, advisory committees and document series that actually exist in the official document titles — nothing is invented. Each document is assigned to one primary group; cross-cutting documents are noted in the group note-line.

Data source

This classification shares its source with the full-list volume “A2LA Accreditation Documents (Full List)”, compiled from the official A2LA public document portal (https://portal.a2la.org/documents/) captured 2026-10-19; it covers 99 current public documents, grouped by the accreditation programmes, advisory committees and document series that actually exist in the official titles. Official links for each document are in the companion full-list volume. All documents are subject to the current A2LA official versions.

Usage note

The A2LA website is organised by document type (Organization / Information / Policies / Requirements / Guidance / Forms) and has no industry segmentation; the “general + special” grouping here is a secondary arrangement for field-based browsing. Withdrawn / superseded versions are not listed; controlled documents such as R261 (EMLAP), available on request, are not in the public listing.
