常见问题

准备 agent 是什么？
它是一个交互式工作台：把你组织的几项事实（标准、行业、实验室类型、阶段、范围）转化为一份个性化准备卷宗。不是通用清单，而是按你的实际情况排好严重度的缺口、以及关闭每个缺口所用的工具与文档。
agent 免费吗？
免费。agent 和你的就绪度卷宗均免费、无需登录。只有在你选择生成某份文档、出具不确定度报告或购买准备包时才付费；现实诊断永久免费。
agent 能替代认证／认可吗？
不能。它帮你组织准备工作并链接到各工具——不颁发证书、不作认可决定、不出审核结论。请始终对照现行标准文本与认可机构规则核验输出。
覆盖哪些标准？
ISO 9001（2015 与 2026）、ISO 14001（2015 与 2026）、ISO/IEC 17025（2017）、ISO 45001（2018）与 IATF 16949（2016）。选择你的标准与版本即可启动对应 agent。
