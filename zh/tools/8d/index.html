框架 / 标准
8D 叙述（可编辑步骤）
D0 — 计划 / 症状与紧急响应
描述触发 8D 的症状，以及已采取的紧急响应（遏制、通知客户等）。
D1 — 建立团队
列出跨职能团队及每位成员的岗位职责（负责人、工艺、质量、设计、物流…）。
D2 — 问题描述（5W2H + Is/Is-Not）
使用 5W2H（谁/什么/何时/何地/为何/如何/多少）与 Is/Is-Not 分析，精确界定问题边界。
D3 — 临时遏制措施（ICA）
定义保护客户的临时遏制措施（ICA），并说明其有效性如何被验证。
D4 — 根本原因分析（鱼骨图 + 5-Why）
查找根本原因：发生原因、流出（探测）原因与系统原因。用鱼骨图（4M/6M）+ 5-Why，再以数据验证。
D5 — 永久纠正措施（PCA）
选择能消除根本原因的永久纠正措施（PCA），并说明其验证方式。
D6 — 实施并验证 PCA
在生产中实施 PCA 并验证（确认未引入新的问题）。
D7 — 防止再发生（PFMEA / 控制计划）
防止再发生：更新 PFMEA、控制计划、体系文件、作业指导书与培训。
D8 — 表彰团队并关闭
表彰团队，并在客户/管理层确认后关闭 8D。

D0 — 计划 / 症状与紧急响应
症状：客户 A 产线判定连接器 P/N 12345 间歇性接触电阻超标（实测 >50 mΩ，规格 ≤20 mΩ），流出比例 0.8%。应急响应：出货码头 100% 全检成品；隔离 3 个可疑批次（12,000 件）；24 小时内通知客户。
D1 — 建立团队
跨职能 8D 小组——组长：张工（质量经理）；成员：李工（工艺）、王工（制造）、刘工（供应商质量 SQE）、陈工（设计）、赵工（QA 检验员）、孙工（物流）。
D2 — 问题描述（5W2H + Is/Is-Not）
5W2H——谁：客户 A 最终检验操作员。什么：接触电阻超出 20 mΩ 规格。何时：2026-09-12 发现，2026-08 起呈现趋势。何地：客户 A 来料检验 3 线。为何：间歇性，非每件必现。如何：四线法毫欧计测量。多少：96 / 12,000（0.8%）。 是：出现在批次 L2408xx–L2409xx、右侧触点。 非：左侧触点未出现；同工位组装的其他料号未出现；内部终检未捕获（内部直通率 100%）。
D3 — 临时遏制措施（ICA）
临时措施（ICA）：码头 100% 全检（采用同一四线法方法）；可疑批次封锁禁止出货；在客户 A 端增加来料筛选。有效性验证：连续 5 天，全检后未再检出 >20 mΩ 逃逸（每班抽样 2,000 件）。
D4 — 根本原因分析（鱼骨图 + 5-Why）
鱼骨图（4M）：料——电镀槽液厚度波动；机——无在线镀层厚度检测；法——镀层厚度规格窗口过宽；人——操作员跳过 SPC 抽样。 发生原因 5-Why：接触电阻高 → 镀层厚度低于 1.5 μm → 槽液浓度漂移 → 无在线监控 → SPC 未强制执行。 流出原因 5-Why：内部测试通过 → 抽样方案覆盖不了间歇性缺陷 → 未 100% 检测 → 探测缺口。 系统原因：控制计划未要求在线厚度 SPC；PFMEA 中镀层漂移 RPN 评分偏低。 根因验证：10 件不良品切片确认镀层厚度 0.9–1.3 μm（规格 ≥1.5 μm）。
D5 — 永久纠正措施（PCA）
永久措施（PCA）：(1) 镀层厚度增加 SPC（X̄-R 图，每批，规格 1.5–3.0 μm，Cpk≥1.33）；(2) 电镀出口加装在线镀层测厚仪 + 自动剔除防错；(3) 收紧电镀槽液浓度控制 + 每日滴定；(4) SPC 验证通过前维持 100% 四线法电阻测试。 试产批 5,000 件验证：0 不良，Cpk 1.6。
D6 — 实施并验证 PCA
已在 A、B 产线实施（2026-10-02）。验证：30 天运行、240,000 件、0 高电阻逃逸；SPC 受控（Cpk 1.5–1.8）；未引入新缺陷（直通率维持 99.2%）。连续 2 周清洁数据后客户 A 恢复出货。
D7 — 防止再发生（PFMEA / 控制计划）
更新 PFMEA：调高镀层厚度漂移发生度评分；增加在线测厚探测控制。更新控制计划：强制在线 SPC + 自动剔除。修订电镀作业指导书并完成操作员培训与认证。同步推广至生产同族产品的姊妹厂。经验教训录入 CAPA 知识库。
D8 — 表彰团队并关闭
团队在月度质量评审上获表彰并颁发证书。客户确认 30 天清洁运行后，8D 于 2026-10-30 正式关闭。最终报告归档；经验教训向全球质量网络分享。
结论
  1. 用客观数据验证 D4 根因（鱼骨图 + 5-Why，区分发生/流出/系统三类原因）——未经验证的根因是 8D 在审核中最常被退回的一项。
  2. 务必在 D7 更新 PFMEA 与控制计划，并落实培训与标准化——很多 8D 在审核时栽在“未真正防止再发”。
  3. 报告含 D0–D8 全文与完成度摘要，可直接导出 Word 归档或提交客户/评审。

关于本工具

8D 是用于解决反复性或高影响问题、并彻底关闭的团队八步法——源自美国汽车业，如今普遍用于 ISO 9001 与 IATF 16949 纠正措施体系。它强制纪律：先遏制症状、找到真正根因、再防止再发。

本工具提供结构化的 D0-D8 表单——从应急响应（D0/D1）、遏制（D3）、5-Why 与鱼骨图提示的根因分析（D4）、纠正与预防措施（D5/D6/D7）到关闭经验教训（D8）。描述问题，即得一份顾客会接受的专业的 8D 报告。

常见问题

八个 D 步骤是什么？

D0 准备/应急响应；D1 组建团队；D2 描述问题（5W2H）；D3 临时遏制；D4 根因分析（5-Why/鱼骨图，发生与逃逸）；D5 选定永久纠正措施；D6 实施并验证；D7 防止再发（体系、FMEA、控制计划）；D8 表彰团队并关闭。遏制（D3）必须先于根因，绝不可后置。

8D 和 CAPA 一样吗？

8D 是 CAPA 的一种严谨格式，不是不同概念。在 ISO 9001 / IATF 16949 下你需要纠正与预防措施；8D 只是把遏制、根因与预防包进八个有文件记录、有团队负责人的步骤里，是广泛接受的载体。

为什么遏制（D3）如此重要？

在你还不知道根因时，遏制保护顾客——阻止更多不良件流出、隔离可疑库存并验证临时措施有效。跳过或拖延 D3 是 8D 被顾客驳回最常见的原因。
