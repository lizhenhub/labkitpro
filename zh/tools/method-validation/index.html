关于本工具

方法验证是在测量程序投入常规使用前，证明其确实产出准确、适用结果的过程。四大核心参数是准确度（加标回收率）、精密度（重复性/中间精密度）、线性（响应vs浓度）以及检出限与定量限。

接受准则对照既定惯例：回收率 80-120%（痕量分析更严）、精密度对照 Horwitz RSDR、线性相关系数 r >= 0.99、检出限用 IUPAC 3.3σ 法、定量限用 10σ。这些阈值来自 Eurachem、AOAC 与 IUPAC 指南，也是 ISO/IEC 17025 评审员期望看到的记录。

常见问题

回收率多少算可接受？

多数分析物通行接受窗为回收率 80-120%；痕量方法常收紧（如 90-110%），因为低浓度下微小偏差影响更大。在方法中写明自己的判据，并逐一对每次加标判定，而非套用笼统数字。

精密度怎样对照 Horwitz 判定？

Horwitz 公式预测方法在质量分数 C 处的相对标准差 RSDR = 2^(1 - 0.5 log10 C)。测得 RSD 接近或低于 RSDR 即为可接受；远高于它说明方法控制差。这是一个筛查基准而非强制判据——应与你的规格配套使用。

LOD 和 LOQ 有什么区别？

LOD（检出限）是方法能可靠区别于空白的最小量——IUPAC 定义为信噪比达 3.3σ 处的信号。LOQ（定量限）是能以可接受精密度与准确度测定最小量，常用 10σ。两者都必须报告，并给出实际实验依据。
