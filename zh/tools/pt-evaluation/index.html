关于本工具

能力验证（PT）是实验室证明其结果与同行可比的方式。每一轮给你一个指定值 X 与能力评定标准差 σ；你的任务是把实验室结果 x 转化为成绩，并在成绩差时做出反应。

z 分数 z = (x - X) / σ 是主力判据：|z| <= 2 满意、2 < |z| < 3 可疑、|z| >= 3 不满意。当你还知道自身不确定度时，更严格的 En 值 En = (x - X) / √(σ² + u²) 把实验室不确定度纳入判定。任何不满意结果都必须按 ISO/IEC 17025 触发纠正措施并通知客户。

常见问题

z 分数等于 3 意味着什么？

z 分数达到或超过 ±3 为不满意：你的结果离指定值三个标准差，是性能失败的常规分界线。必须查因、采取纠正措施，并依 ISO/IEC 17025 记录并通知受影响客户。

什么时候用 En 值而不是 z？

当你已知实验室不确定度 u、并想要一个更严格、计入不确定度的分数时用 En。En = (x - X) / √(σ² + u²)；|En| <= 1 判定合格。当 u 相对 σ 不可忽略时优先用 En，因为它不会惩罚一个落在其自身不确定度范围内的结果。

多少轮 PT 才算趋势？

一次不满意 z 是待查的孤立事件；多轮 |z| 接近或超过 2 则指向系统性问题（偏倚、校准漂移、基体效应）。长期跟踪 z 分数——滚动图远比单轮更有信息量。
