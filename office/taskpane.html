Every tool follows the same 3 steps:
  1. Select a range of cells in your sheet (the data to analyze).
  2. Set the parameters shown on the tab (spec limits, chart type, etc.).
  3. Click Analyze (or Run Gage R&R). Results + charts appear here.

Everything runs offline — your data never leaves Excel. New here? Click Sample data on any tab to auto-fill a demo dataset, then Analyze it.

Cpk · Process capability

  • Select one column of measurements → enter LSL / USL (Target optional) → Analyze.
  • Select 2+ columns → each column is one subgroup (enables Cp / Cpk).
  • Leave one spec limit blank for a one-sided spec.

SPC · Control charts

  • Pick a chart type from the dropdown — the hint updates to tell you the layout.
  • Subgroup charts (X̄-R / X̄-S / Median): each column = one subgroup (2–10 rows).
  • I-MR: one column of individual readings (time-ordered).
  • Attribute (p / np / c / u): 2 columns — sample size n and defect count / defects.

MSA · Gage R&R

  • Set Appraisers / Trials / Parts, then select the measurement table.
  • Rows = appraiser × trial (appraiser 1 trial 1…n, then appraiser 2…); columns = parts.
  • Tolerance is optional — if blank, %GRR is reported against total variation.

Cg / Cgk · Measurement capability

  • Select the measurement column, then enter the Reference (true value) and Tolerance (USL − LSL).
  • VDA 5 rule: Cg ≥ 1.33 and Cgk ≥ 1.33 = accept.

Reports & Sample data

  • Insert report — writes the text report into the current selection (you're asked to confirm first).
  • Copy report — copies a plain-text report to your clipboard.
  • Download report — saves a self-contained HTML file (charts + metrics + method) you can open or email.
  • Sample data — fills a demo dataset into the sheet. Click a single empty cell first (or a range at least as big as the sample); otherwise Excel can't fit the block and will reject the write. After loading, just click Analyze — you don't need to re-select the data (it's remembered).
  • Import external data (top bar) — paste values from a CSV / another sheet / text file; columns split by tab, comma or space. Analysis runs on the pasted data regardless of the write.
