Thresholds per AIAG SPC: capable ≥ 1.33 · marginal 1.00–1.33 · not capable < 1.00

Western Electric / Nelson rules: ① beyond limits ② 2-of-3 beyond 2σ ③ 4-of-5 beyond 1σ ④ 8 same side ⑤ 6 trending

Gage R&R (AIAG, X̄-R) — select the measurement table: rows = appraiser × trial (appraiser 1 trial 1…n, then appraiser 2…), columns = parts. Leave Tolerance blank to report %GRR against total variation.

AIAG MSA: %GRR ≤ 10% acceptable · 10–30% conditional · > 30% not acceptable. NDC ≥ 5 required.

Bias (AIAG ch. III, exact t-test) — select a single column of repeated measurements taken on the same reference (true) value. ≥ 5 readings.

Exact t-test vs t-critical (df = n−1, α = 0.05) per AIAG MSA ch. III.

Linearity (AIAG ch. III, regression) — select a 2-column range: column 1 = reference value, column 2 = measured value. One row per reference level, ≥ 4 levels.

Linearity = |slope| × span · ≤ 5% of tolerance acceptable (AIAG MSA ch. III).

Stability (drift over time) — select the table where each row = one time point's repeated measurements on the same reference (equal count per row, ≥ 2 rows).

X̄-R limits across time-group means (AIAG MSA ch. III).

Attribute agreement (AIAG ch. IV, Kappa) — select a 3-column range: column 1 = appraiser (text, e.g. A / B / C), column 2 = actual judgement (pass/fail), column 3 = reference judgement. ≥ 5 rows.

Agreement + Cohen's Kappa vs reference (AIAG MSA ch. IV).

Measurement capability (VDA 5) — select the measurement column in the sheet, then enter the reference (true) value and the tolerance band (USL−LSL).

VDA 5: Cg ≥ 1.33 and Cgk ≥ 1.33 = accept (20% tolerance / 10% tolerance rule).

Every tool follows the same 3 steps:

Everything runs offline — your data never leaves Excel. New here? Click Sample data on any tab to auto-fill a demo dataset, then Analyze it.

Cpk · Process capability

  • Select one column of measurements → enter LSL / USL (Target optional) → Analyze.
  • Select 2+ columns → each column is one subgroup (enables Cp / Cpk).
  • Leave one spec limit blank for a one-sided spec.

SPC · Control charts

  • Pick a chart type from the dropdown — the hint updates to tell you the layout.
  • Subgroup charts (X̄-R / X̄-S / Median): each column = one subgroup (2–10 rows).
  • I-MR: one column of individual readings (time-ordered).
  • Attribute (p / np / c / u): 2 columns — sample size n and defect count / defects.

MSA · 5 studies (AIAG)

  • Gage R&R — set Appraisers / Trials / Parts, select the table (rows = appraiser × trial, columns = parts).
  • Bias — one column of repeated readings on a reference value + t-test.
  • Linearity — 2 columns: reference, measured (one row per level, ≥ 4).
  • Stability — each row = one time point's readings on the reference (drift check).
  • Attribute — 3 columns: appraiser, actual, reference (pass/fail) → agreement + Kappa.

Cg / Cgk · Measurement capability

  • Select the measurement column, then enter the Reference (true value) and Tolerance (USL − LSL).
  • VDA 5 rule: Cg ≥ 1.33 and Cgk ≥ 1.33 = accept.

Reports & Sample data

  • Insert report — writes the text report into the current selection (you're asked to confirm first).
  • Copy report — copies a plain-text report to your clipboard.
  • Download report — saves a self-contained HTML file (charts + metrics + method) you can open or email.
  • Sample data — works from anywhere, any time: click it and a typical demo dataset is placed at the top of the sheet (cell A1) and selected for you. If that spot is busy, the data is simply kept in memory — either way Analyze runs on it immediately, no selection needed.
  • Import external data (top bar) — paste values from a CSV / another sheet / text file; columns split by tab, comma or space. Analysis runs on the pasted data regardless of the write.
