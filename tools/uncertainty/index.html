2 · Measurement model

Y = Σ cᵢ·xᵢ (default linear model)

The model relates the measurand Y to input quantities xᵢ; cᵢ = ∂Y/∂xᵢ is the sensitivity coefficient, taken as 1 when dimensionless.

3 · Sources & uncertainty budget

4 Resolution (Type B, uniform) B uniform Type B · rectangular (half-width a, equiprobable) → u=a/√3 0.002900 1 0.002900 50

“Basis of evaluation” states how each uᵢ is obtained (Type A = statistical, Type B = non-statistical); “|cᵢ|·uᵢ” feeds the combination and contribution analysis.

Reference · Type B distribution divisors (GUM / NABL-141)

  • Rectangular (half-width a, equiprobable): u = a/√3
  • Triangular (half-width a, mid more likely): u = a/√6
  • Digital resolution ±d/2: treat as rectangular, u = (d/2)/√3
  • Certificate gives expanded U: u = U/k (k is its coverage factor; 95%→k=2, 99%→k=2.58)
  • Avoid “double-counting”: an effect already captured by the Type A statistical spread must not be re-entered as a Type B component.

4 · Combined standard uncertainty

u_c = √Σ(cᵢ·uᵢ)² = √((1×0.020000)² + (1×0.015000)² + (1×0.005800)² + (1×0.002900)²) = 0.025827

(rounded to 3 s.f.: u_c ≈ 0.0258)

Combination assumptions

① Input estimates are treated as uncorrelated (rᵢⱼ = 0) and combined by RSS; if any two components are strongly correlated (|r| > 0.5, e.g. one reference standard used for both calibration and check), the covariance form (GUM §5.2) must be used and this report re-checked. ② Non-linearity of the model is negligible for small input uncertainties (PTB/EURAMET practice); otherwise validate by MCM (JCGM 101).

5 · Effective degrees of freedom

ν_eff = u_c⁴ / Σ[(cᵢ·uᵢ)⁴ / νᵢ] = 24

Welch–Satterthwaite formula; an unknown component df is treated by its type default (Type A uses actual n−1, Type B treated as very large → approx. infinite).

6 · Coverage factor

k = 2　·　Derived from the t-distribution at ν_eff (two-sided 95% confidence); a manually set k overrides this.

7 · Expanded uncertainty

U = k·u_c = 2 × 0.025827 = 0.051655

Rounded to at most two significant figures: U ≈ 0.052 mm.

8 · Report statement

The measured result of the measurand Length is reported as Y = …; the expanded uncertainty is U = 0.052 mm (k = 2, approximately 95% confidence). The result and its uncertainty are evaluated and expressed per GUM.

10 · Dominant component & recommendations

The expanded uncertainty is dominated by Repeatability (Type A), contributing about 60%.

  • Cutting this component by about half (e.g. more repeats to reduce a Type A component, or a higher-grade reference standard to reduce a Type B component) could bring U from 0.0517 down to about 0.0383 mm.
  • Check each “Basis of evaluation” above: Type B components should cite a valid certificate/manual and use the correct distribution divisor (rectangular √3, triangular √6, normal per certificate); Type A degrees of freedom ν=n−1 must match the number of repeats.
  • Prioritise the top one or two contributors — usually the cheapest way to materially shrink U.

11 · Conformity & reporting requirements (ISO/IEC 17025:2017 · 7.6)

  • Uncertainty is evaluated per GUM (JCGM 100:2008); in calibration, CMC states measured quantity / method / range / U in the scope.
  • Expanded uncertainty is given at approximately 95% confidence with the coverage factor k stated; relative expressions such as ppm/ppb are avoided.
  • Results are reported as “y ± U” with a statement of how the uncertainty was obtained.
  • U is rounded to at most two significant figures; u_c keeps one extra figure.
  • CMC intervals are closed (no open intervals such as 0<U<x); reported uncertainty must not be smaller than the accredited CMC.
  • Testing: uncertainty is evaluated and reported whenever it affects validity of results, client requirements, or conformity decisions.

❓ Beginner FAQ

What is uncertainty, really?
It is “how unsure the measurement is”. If you measure 100 N with U = 2 N, the true value is within 98–102 N with about 95% confidence.

Type A vs Type B?
Type A = computed from repeated readings (data speaks); Type B = taken from certificates/handbooks/experience (e.g. U÷k on a calibration certificate). Both feed the same combination formula — neither is “better”.

How do I read U in the report?
Results are written “y ± U”; k = 2 means about 95% confidence. U keeps at most 2 significant figures — rounding is handled automatically per GUM.
