ISO/IEC 17025

About this tool

Calibration proves a measuring device was capable on one day; intermediate checks prove it has stayed capable every day since. An IMC is a routine check performed between calibrations using a check standard, reference material or verified reference value, so drift, wear or shock are caught before they corrupt results.

Two standard evaluation methods are built in. The control-chart method plots each check against the center (the reference value, or the mean if none) with action limits at +/- k sigma (k = 3 by default) and warning limits at +/- 2 sigma. The En-value method compares each check to the certified reference value with En = (y - X) / sqrt(U_lab^2 + U_ref^2) and accepts when |En| <= 1. Both U_lab and U_ref must be expanded uncertainties at the same coverage factor (normally k = 2).

Frequently asked questions

Does an intermediate check replace calibration?

No. IMC monitors capability between calibrations; it never re-establishes traceability or the calibration interval. An out-of-control check means you must investigate and may need an interim calibration, but the scheduled calibration interval itself is unchanged unless a documented justification supports it.

Which is better: En-value or control chart?

They answer different questions. Use the En-value method when you have a certified reference value and its uncertainty - it gives the strictest, uncertainty-aware pass/fail per check. Use the control-chart method when no certified reference is available and you only want to watch stability and trend over time. Many labs run both: a reference standard for En plus a control chart of routine checks.

What control-limit factor k should I use?

k = 3 (+/- 3 sigma) is the conventional action limit for an IMC control chart; k = 2 (+/- 2 sigma) is commonly drawn as a warning limit so a drift is caught early. Use k = 3 as the hard out-of-control criterion and treat points between 2 sigma and 3 sigma as a trend to watch, not yet a failure.
