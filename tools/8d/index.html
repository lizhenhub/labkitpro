Framework / standard
8D narrative (editable steps)
D0 — Plan / Symptom & Emergency Response Action
Describe the symptom that triggered the 8D and any emergency response already taken (containment, customer notification).
D1 — Establish the Team
List the cross-functional team and each member’s role (leader, process, quality, design, logistics…).
D2 — Describe the Problem (5W2H + Is/Is-Not)
Use 5W2H (Who/What/When/Where/Why/How/How many) and an Is / Is-Not analysis to bound the problem precisely.
D3 — Interim Containment Action (ICA)
Define the interim containment action that protects the customer, and how its effectiveness was verified.
D4 — Root Cause Analysis (fishbone + 5-Whys)
Find the root cause(s): occurrence, detection (escape) and systemic. Use a fishbone (4M/6M) + 5-Whys, then verify with data.
D5 — Permanent Corrective Action (PCA)
Select the Permanent Corrective Action that removes the root cause, and state how it was verified.
D6 — Implement & Validate PCA
Implement the PCA in production and validate (confirm no new problems were introduced).
D7 — Prevent Recurrence (PFMEA / Control Plan)
Prevent recurrence: update PFMEA, Control Plan, systems, work instructions and training.
D8 — Congratulate the Team & Close
Recognize the team and close the 8D after customer / leadership confirmation.

D0 — Plan / Symptom & Emergency Response Action
Symptom: Customer A line rejects connector P/N 12345 due to intermittent high contact resistance (>50 mohm vs spec <=20 mohm) on 0.8% of shipped units. Emergency response: 100% sort of finished goods at the shipping dock; quarantine of 3 suspect lots (12,000 pcs); customer notified within 24 h.
D1 — Establish the Team
Cross-functional 8D team — Team leader: J. Smith (Quality Manager); Members: R. Lee (Process Eng.), M. Chen (Manufacturing), A. Patel (SQE), T. Muller (Design Eng.), S. Garcia (QA inspector), K. Tan (Logistics).
D2 — Describe the Problem (5W2H + Is/Is-Not)
5W2H — Who: final-test operators at Customer A. What: contact resistance exceeds the 20 mohm spec. When: detected 2026-09-12, trend since 2026-08. Where: Customer A incoming inspection, line 3. Why: intermittent, not every unit. How: measured with a 4-wire milliohm meter. How many: 96 / 12,000 (0.8%). Is: occurs on lot range L2408xx-L2409xx, right-side contact. Is-Not: not on the left contact; not on other P/Ns built in the same cell; not caught by internal final test (internal pass rate 100%).
D3 — Interim Containment Action (ICA)
ICA: 100% sort at the dock using the same 4-wire method; suspect lots blocked from shipment; added incoming screening at Customer A. Effectiveness verified: 5 consecutive days, 0 escapes of >20 mohm detected post-sort (sample 2,000 / shift).
D4 — Root Cause Analysis (fishbone + 5-Whys)
Fishbone (4M): Material — plating bath thickness variation; Machine — no inline coating-thickness check; Method — plating thickness spec window too wide; Man — operator skipped SPC sampling. Occurrence 5-Whys: high contact resistance -> plating thickness below 1.5 um -> bath concentration drift -> no inline monitoring -> SPC not enforced. Detection (escape) 5-Whys: internal test passed -> sampling plan missed the intermittent defect -> no 100% test -> detection gap. Systemic cause: Control Plan did not require inline thickness SPC; PFMEA RPN for plating drift under-rated. Verified root cause: cross-section of 10 rejects confirmed plating thickness 0.9-1.3 um (spec >=1.5 um).
D5 — Permanent Corrective Action (PCA)
PCA: (1) Add SPC on plating thickness (X-bar/R, every lot, spec 1.5-3.0 um, Cpk>=1.33); (2) Install inline coating-thickness gauge with auto-reject poka-yoke at the plating exit; (3) Tighten plating bath concentration control + daily titration; (4) 100% 4-wire resistance test until SPC is validated. Verified on pilot lot of 5,000 pcs: 0 rejects, Cpk 1.6.
D6 — Implement & Validate PCA
Implemented on production lines A and B (2026-10-02). Validation: 30-day run, 240,000 pcs, 0 high-resistance escapes; SPC in control (Cpk 1.5-1.8); no new defects introduced (FPY maintained 99.2%). Customer A resumed shipments after 2 weeks of clean data.
D7 — Prevent Recurrence (PFMEA / Control Plan)
Updated PFMEA: raised the plating-thickness-drift occurrence rating; added the inline-gauge detection control. Updated Control Plan to mandate inline SPC + auto-reject. Revised the plating work instruction and added operator training + certification. Rolled out to the sister site producing the same family. Added lessons-learned to the CAPA knowledge base.
D8 — Congratulate the Team & Close
Team recognized at the monthly QBR; certificates issued. 8D closed 2026-10-30 after customer confirmation of 30-day clean performance. Final report filed; lessons shared with the global quality network.
Conclusion
  1. Verify the D4 root cause with objective data (fishbone + 5-Whys; separate occurrence, detection/escape and systemic causes) — an unverified root cause is a top 8D rejection reason at audit.
  2. Ensure D7 updates the PFMEA and Control Plan, plus training/standardization — many 8Ds fail audits because recurrence was not actually prevented.
  3. The report contains the full D0–D8 narrative and a completion summary — export to Word for filing or customer / audit submission.

About this tool

8D is the team-based, eight-step method used to solve chronic or high-impact problems and close them out for good - originally a US automotive discipline, now common across ISO 9001 and IATF 16949 corrective-action systems. It forces discipline: contain the symptom first, find the true root cause, then prevent recurrence.

This tool gives you a structured D0-D8 form - from the emergency response (D0/D1), through containment (D3), root-cause analysis with 5-Why and fishbone prompts (D4), corrective and preventive action (D5/D6/D7) and the closure lessons (D8). Describe the issue and get a professional 8D report your customer will accept.

Frequently asked questions

What are the eight D steps?

D0 prepare / emergency response; D1 form the team; D2 describe the problem (5W2H); D3 interim containment; D4 root-cause analysis (5-Why / fishbone, occurrence and escape); D5 choose permanent corrective action; D6 implement and validate; D7 prevent recurrence (system, FMEA, Control Plan); D8 congratulate the team and close. Containment (D3) must come before root cause, never after.

Is 8D the same as a CAPA?

8D is a disciplined format for CAPA, not a different concept. Under ISO 9001 / IATF 16949 you need corrective and preventive action; 8D is simply a widely accepted structure that wraps containment, root cause and prevention into eight documented steps with a team owner.

Why is containment (D3) so important?

Containment protects the customer while you still do not know the root cause - it stops more bad parts shipping, quarantines suspect stock and verifies the interim action works. Skipping or delaying D3 is the most common reason an 8D is rejected by a customer.
